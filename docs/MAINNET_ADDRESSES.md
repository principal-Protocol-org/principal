# Mainnet Addresses — Quick Reference

A single-page lookup of every real Stellar **Public mainnet** address this deployment uses.
No narrative here — for the story behind each one (why it exists, how it was created, every real
transaction hash), see [`docs/MAINNET_DEPLOYMENT_EVIDENCE.md`](MAINNET_DEPLOYMENT_EVIDENCE.md) and
[`docs/MAINNET_TRANSACTION_LEDGER.md`](MAINNET_TRANSACTION_LEDGER.md). For dApp integration, see
[`docs/MAINNET_DAPP_INTEGRATION_GUIDE.md`](MAINNET_DAPP_INTEGRATION_GUIDE.md). Every address below
is live and independently verified (`scripts/deploy/verify-deployment.sh`, 78/79 per market —
the expected `git_tree_dirty` flag is the one non-pass).

repeated here to avoid anyone copy-pasting them by mistake.
